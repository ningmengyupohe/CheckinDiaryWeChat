# CheckinDiaryWeChat

#### 介绍
打卡日记微信小程序是一款面向学生与职场人士的习惯养成与目标管理工具，核心功能包括：
- 打卡项目创建与管理（支持自定义/模板创建）
- 每日打卡与凭证上传
- 打卡数据可视化统计（趋势、完成率、连续天数）
- 成就徽章激励系统
- 本地数据存储与跨设备数据导出/导入
界面简洁、操作便捷，无需安装，微信直接打开使用，助力用户高效养成习惯、追踪成长。

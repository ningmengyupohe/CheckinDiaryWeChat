# 打卡日记微信小程序

一款轻量化、离线可用的习惯养成与目标管理微信小程序，帮助用户追踪日常打卡、培养自律习惯、记录成长轨迹。

---

## ✨ 项目简介
打卡日记微信小程序基于微信生态开发，无需下载安装，打开即用。面向学生、职场人士等有习惯养成、目标管理需求的用户，提供从打卡创建、每日签到到数据统计、跨设备数据迁移的全流程支持，数据本地存储，保障隐私安全。

---

## 🚀 核心功能
- **打卡项目管理**：支持自定义创建打卡项目，或选用阅读、运动、学习等预设模板，可设置目标天数、提醒时间、项目描述。
- **每日打卡签到**：支持一键打卡，可上传图片作为打卡凭证，重复打卡自动拦截，目标完成后自动终止打卡流程。
- **数据可视化统计**：按周/月/年维度展示打卡总天数、完成率、连续打卡记录，通过图表直观呈现打卡趋势与项目完成度。
- **成就激励系统**：设置多档成就徽章，满足连续打卡、总打卡数等条件即可自动解锁，提升打卡动力。
- **数据安全与迁移**：所有数据本地存储，不上传服务器；支持数据导出为JSON格式备份，跨设备导入恢复，避免数据丢失。

---

## 📱 使用说明
1.  打开微信，搜索或扫码进入「打卡日记」小程序，完成微信一键授权登录。
2.  在「操作」页面创建/编辑/删除打卡项目，设置打卡目标。
3.  进入项目详情页，点击「打卡」完成每日签到，可上传凭证。
4.  在首页查看数据总览，进入「数据分析」查看打卡趋势与统计信息。
5.  在「我的」页面管理个人信息、查看成就徽章、导出/导入打卡数据。

---

## ⚠️ 注意事项
- 小程序仅获取微信头像、昵称，不收集手机号、地理位置等敏感隐私信息。
- 所有数据存储在设备本地，清除微信缓存、更换设备会导致数据丢失，建议定期导出数据备份。
- 导入数据会覆盖当前本地数据，操作前请确认已备份当前数据。
- 无网络状态下，仅天气展示、分享功能受影响，打卡、项目管理等核心功能可正常离线使用。
